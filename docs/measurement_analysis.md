# ASG Airlines — Measurement & Validation Analysis

## 1. Purpose

This file records a few measurable results from the data pipeline and the final analytical datasets.

The purpose is to show that the pipeline was not only used to clean the data, but also checked using actual counts, percentages and validation results.

All measurements below are based on the outputs generated by the project.

---

## 3. Data Quality Measurements

### Flight validation

Valid flight records:

**1004 / 1005 = 99.90%**

Quarantined flight records:

**1 / 1005 = 0.10%**

The quarantined record had an arrival timestamp earlier than its departure timestamp and could not be resolved as a valid overnight flight.

---

### Payment validation

Valid payment transactions:

**922 / 1000 = 92.20%**

Invalid payment records:

**78 / 1000 = 7.80%**

The invalid records include missing payment amounts and records containing the literal value `INVALID`.

---

### Referential integrity

The pipeline checked the relationships between:

- Bookings → Passengers
- Bookings → Flights
- Payments → Bookings

The validation results showed:

**0 orphan passenger references**

**0 orphan flight references**

**0 orphan payment references**

This means the records remaining in the analytical layer have valid references across these relationships.

## 4. Flight Duration Measurements

The final Gold flight dataset contains:

**1004 valid flight records**

Average flight duration:

**164.49 minutes**

Median flight duration:

**166 minutes**

The median is close to the average, which indicates that the overall duration values are not being driven heavily by a small number of extreme values.

---

## 5. Overnight Flight Measurement

Valid overnight flights:

**122**

Total valid flights:

**1004**

Overnight flight percentage:

**122 / 1004 × 100 = 12.15%**

Therefore, approximately **12.15% of valid flights** in the final analytical dataset are overnight flights.

Overnight handling was performed by comparing the parsed departure and arrival timestamps. When the arrival timestamp falls on the following day, the duration is calculated across the date boundary rather than treating the arrival as occurring before departure.

---

## 6. Duration Validation

The pipeline compares the calculated duration with the duration supplied in the source data wherever a source duration is available.

After transformation:

**Duration mismatches = 0**

This indicates that the calculated duration values in the final Gold flight dataset matched the available source duration values for the records that passed validation.

## 7. Airline Data Quality

The cleaned flight data contains:

**39 records with missing airline values**

and

**69 records with UNKNOWN airline values**

These values were not automatically assigned to another airline because there was not enough reliable information to determine the correct airline.

Keeping the values as missing/UNKNOWN avoids introducing assumptions into the analytical data.
